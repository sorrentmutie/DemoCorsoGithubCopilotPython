# DemoCorsoGithubCopilotPython

## Gioca a tris

Avvia il gioco dal terminale con Python 3:

```bash
python3 tic_tac_toe.py
```

Due giocatori si alternano scegliendo una casella da 1 a 9; il primo gioca con
`X` e il secondo con `O`. Le caselle disponibili sono indicate sulla griglia.
Per eseguire i test:

```bash
python3 -m unittest -v
```
